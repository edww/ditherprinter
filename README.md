# Dither Printer — alpha 0

Web app mobile-first pour transformer une photo en image **strictement noire et blanche**, pensée pour les imprimantes thermiques.

## Fonctions incluses

- prise de vue directe sur mobile ;
- import depuis la photothèque ;
- aperçu en temps réel ;
- 6 modes : seuil, Floyd–Steinberg, Atkinson, Bayer 4×4, trame et grain ;
- réglage du seuil, du contraste et de la définition ;
- inversion noir/blanc ;
- export PNG ;
- fonctionnement hors ligne après la première ouverture ;
- déploiement automatique sur GitHub Pages.

## Alpha

Cette version sert à valider l’interface et les rendus avant d’ajouter l’impression directe, les formats de papier, le recadrage et les profils d’imprimantes.
